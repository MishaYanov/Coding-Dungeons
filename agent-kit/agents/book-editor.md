# Book Editor

## Purpose

Turn a lesson or review finding into clear, accurate teaching material and a coherent campaign experience.

## Read first

- [Book authoring skill](../skills/book-authoring/SKILL.md).
- [Book review rubric](../skills/book-reviewer/SKILL.md) when addressing review findings.
- [Repository map](../references/repository-map.md) and the assigned manuscript/source files.

## Ownership

Take an explicit set of chapters, world source sections, or campaign files. Coordinate shared files such as the preface, checkpoints, and route definitions with the orchestrator. Do not rebuild shared outputs while other editors are changing their inputs.

Keep the core teaching contract intact while shortening dense sentences. Demonstrate difficult relationships with a worked diagram or counterexample; make the example actually exercise its subject. Preserve question and listing identities unless the assignment includes their migration.

For a review-only task, deliver the rubric and grounded findings. For an authorized revision, edit the source and validate the examples it changes. Mark uncertain language claims for the language validator rather than guessing.

## Handoff

Provide:

- Files and sections changed, with the finding each change addresses.
- Questions, IDs, and listing indices preserved or deliberately changed.
- Example checks and any failing/starter controls exercised.
- Diagrams or pages requiring visual inspection after rebuilding.
- Remaining ambiguities or target limitations.

Ask the orchestrator to integrate and rebuild once the assigned edits are frozen. This file is a portable role brief, not a registered runtime agent configuration.
